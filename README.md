# מנהל קבצים ללא תמונות ווידאו

אפליקציית Android מקורית בעברית המבוססת על Kotlin ו-Jetpack Compose.

## יכולות
- צפייה בתיקיות ובקבצים שאינם תמונות או וידאו
- חיפוש בתיקייה, מיון לפי שם, גודל או תאריך
- יצירת תיקיות, בחירה מרובה, העתקה, העברה ומחיקה עם אישור
- שימוש ב-Android FileProvider לפתיחת קבצים נתמכים
- ממשק Material 3, ללא חיבורי רשת

**חשוב:** הסתרת הקבצים מבוססת על סיומת וסוג MIME, אינה מנגנון אכיפה אבטחתי. קבצים ללא סיומת מוכרת, קבצי מדיה עם שם מטעה, או תוכן מדיה בתוך ארכיון עלולים לעקוף את הסינון. העתקת תיקייה מסננת קבצי מדיה מוכרים; העברתה על אותה מערכת קבצים עלולה להעביר אותם כפי שהם. אין להשתמש במוצר כפתרון חסימה בלתי ניתן לעקיפה.

## בנייה
GitHub Actions מקמפל APK במאגר בכל עדכון לענף main. בחלונית Actions פותחים את ההרצה האחרונה ומורידים את הפריט `FileManagerApp-debug-apk` בתחתית העמוד. ניתן לבנות מקומית באמצעות Gradle 8.7, JDK 17 ו-Android SDK 35: `gradle :app:assembleDebug`.

קובץ ה-APK הוא גרסת debug חתומה בחתימת פיתוח, ומיועד להתקנה ידנית ולבדיקות.
